# ЕНТ-трекер

Сайт для школы: ученики сами регистрируются и вносят результаты пробных ЕНТ, учителя видят всех учеников, динамику и зону риска.

## Запуск в VS Code

Нужен Node.js 20.6 или новее (https://nodejs.org) и PostgreSQL — локальный или облачный.

1. Откройте папку проекта в VS Code (File → Open Folder).
2. Откройте терминал (Ctrl+`) и выполните:
   ```
   npm install
   ```
3. Создайте базу PostgreSQL (например, в панели облачного хостинга). Если `.env` ещё нет, скопируйте `.env.example` в `.env`; если уже есть — не перезаписывайте его, а добавьте или обновите нужные значения:
   - `DATABASE_URL` — строка подключения PostgreSQL от хостинга или локального сервера;
   - `JWT_SECRET` — длинная случайная строка;
   - `TEACHER_CODE` — секретный код для регистрации учителей.
4. Запустите:
   ```
   npm start
   ```
5. Откройте http://localhost:3000

## Как пользоваться

**Учитель**
1. На странице входа откройте вкладку «Первая настройка (учитель)» и создайте аккаунт с кодом из `.env`.
2. «Ученики» → «Добавить учеников»: вставьте список (Фамилия Имя; Класс; Профиль 1; Профиль 2), можно из Excel. Сайт сам создаст логины и пароли. Скачайте таблицу с паролями и раздайте ученикам: пароли показываются один раз.
3. «Тесты и баллы» → задайте период и нажмите «Создать все вторники и пятницы». Лишние дни (каникулы, праздники) удалите.
4. После каждого теста выберите день и класс, впишите баллы и нажмите «Сохранить баллы». Пустая строка ученика означает пропуск.
5. В карточке ученика можно поменять фамилию, класс, профильные предметы, цель, сбросить пароль или удалить ученика.

**Ученик**
- Сам не регистрируется и ничего не меняет. Заходит с логином и паролем от школы и видит только свои результаты: последний, лучший и средний балл, график, сколько тестов написано и пропущено, сколько осталось до цели.

## Структура

- `server.js` — сервер (Express), API и подключение к PostgreSQL
- `index.html`, `style.css`, `app.js`, `theme.js` — файлы интерфейса в корне проекта
- `.env.example` — шаблон настроек; `.env` — локальные секреты, не отправляемые в Git

## Чтобы сайт был доступен ученикам не только в школьной сети

Нужен хостинг с Node.js и PostgreSQL (например, Render, Railway или VPS с отдельной базой). Перед запуском выставьте `NODE_ENV=production`, задайте `DATABASE_URL`, `JWT_SECRET` и `TEACHER_CODE` и включите HTTPS. Приложение создаёт таблицы при первом запуске.

pgAdmin устанавливать не обязательно: он нужен только как графический интерфейс для просмотра и администрирования PostgreSQL. Для облачной базы обычно достаточно панели хостинга; приложение подключается напрямую по `DATABASE_URL`. Если PostgreSQL запускается локально, можно управлять им через pgAdmin или командную строку.

Существующая SQLite-база автоматически не переносится. Перед переходом сохраните резервную копию и отдельно выполните перенос данных, если в ней есть нужные записи.

### Развёртывание на Render

1. Отправьте актуальный код в GitHub и создайте в Render базу **Postgres**.
2. Создайте **Web Service** из этого GitHub-репозитория. Выберите для сервиса и базы один регион; в команде сборки укажите `npm install`, в команде запуска — `npm start`.
3. В переменных окружения сервиса задайте `NODE_ENV=production`, `DATABASE_URL` (внутреннюю строку подключения Postgres из Render), `JWT_SECRET` (сгенерируйте случайное значение) и `TEACHER_CODE` (свой секретный код).
4. Не используйте бесплатный тариф для реального школьного сервиса: Render указывает ограничения бесплатных ресурсов и не рекомендует их для production. Перед созданием проверьте актуальные тарифы и условия хранения данных.

Подробности: [Render Postgres: создание и подключение](https://render.com/docs/postgresql-creating-connecting), [Render: бесплатные ресурсы и ограничения](https://render.com/docs/free).
